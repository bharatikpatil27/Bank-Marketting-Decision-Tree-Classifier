Week 3 – Decision Tree Classifier

Objective

To build a Decision Tree Classification model that predicts whether a customer will 
subscribe to a bank product or service based on demographic and behavioral data.

Dataset

UCI Bank Marketing Dataset – bank-full.csv

Tools and Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Visual Studio Code

Work Performed

1. Loaded and explored the bank marketing dataset.
2. Prepared and encoded categorical data.
3. Split the dataset into training and testing sets.
4. Built a Decision Tree Classifier.
5. Evaluated the model using accuracy, classification report and confusion matrix.
6. Generated visualizations and saved prediction results.
7. Saved the trained model for future use.

Output Files

- decision_tree_model.pkl
- prediction_results.csv
- decision_tree_report.txt
- decision_tree_charts/

Conclusion

Successfully developed a Decision Tree Classification model to predict customer subscription
 outcomes using the UCI Bank Marketing dataset.
